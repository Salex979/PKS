## Контрольная точка 3
### Описание приложения

Краткое описание: Простое приложение для создания и управления заметками. Данные хранятся только на вашем устройстве.
Полное описание: Simple Notes позволяет легко создавать, редактировать и организовывать текстовые заметки. Все данные сохраняются локально на устройстве, что гарантирует конфиденциальность. Интерфейс интуитивно понятен и не требует обучения.
